# Version 10.0 — Intelligent Expedition Builder

## Core function

Choose a mountain and date. The app creates a conservative expedition draft using the verified standard route, start-point data, weather points, timing model, Trip Builder, and generated readiness systems.

## Generated fields

- trip name
- standard route
- start point
- climb and travel dates
- trail start
- turnaround target
- summit and access weather points
- vehicle/access recommendation
- lodging/camp suggestion
- pack strategy
- required decisions
- generated expedition brief

## Planning posture

- Conservative
- Standard
- Fast-moving group

The posture changes timing estimates only. It does not alter route difficulty or create a safety clearance.

## Expedition brief

The active trip receives a copyable brief covering route, timing, weather, pack strategy, travel/access, and unresolved decisions.

## Safety discipline

Every generated value is a draft. Current route conditions, closures, permits, weather, access, group ability, and judgment must still be verified.

## Preserved

All Version 9.1, 9.0, and 8.6.1 functionality remains present.
