# Version 14.0 — Mountain Intelligence Engine

## Added

Version 14 connects the Expedition Archive to:

- personal pattern summaries
- evidence-based planning observations
- partner history
- gear-term history
- route-learning evidence
- encountered-weather evidence
- Scripture, prayer, and spiritual reflections
- global mountain-history search
- active-trip planning completeness

## Data discipline

The engine uses only archived expedition records, trip records, route profiles, and saved user entries already present on the device.

It does not:

- invent personal history
- rank or score partners
- claim causal weather patterns from sparse data
- declare gear sufficient
- issue continue/abort decisions
- equate planning completeness with safety

## Planning completeness

The displayed percentage measures whether planning fields and manual confirmations are recorded. It always carries an explicit disclaimer that it is not a safety clearance.

## Preserved

All Version 13, 12, 11, 10, 9.1, 9.0, and 8.6.1 functionality remains present.
