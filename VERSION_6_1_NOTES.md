# Version 6.1 — Refined Alpine Edition

This is a surgical refinement of Version 6, not a feature expansion.

## Changes
- Clarifies that civil dawn, sunrise and sunset are astronomical flat-horizon calculations, not terrain-adjusted usable light.
- Adds a visible ridge/terrain caveat to both the sunlight board and Summit Focus.
- Removes the redundant Field Mode; Summit Focus is now the single reduced-information field experience.
- Removes the quick-status ribbon that duplicated dashboard content.
- Rewords the 50+ language so it clearly represents a long-term goal rather than a current total.
- Adds text symbols and border patterns so Night Vision statuses remain distinguishable without relying on color.
- Bumps the service-worker cache version.

No trip logic, weather API architecture, offline behavior, privacy rules or authoritative links were removed.
