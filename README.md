# Don Downs Mountain Guide

Mobile-first progressive web app for the Lake Como expedition and Colorado 14er planning.

## Deploy on GitHub Pages

1. Upload all files in this folder to the root of the `mountain-guide` repository.
2. Keep the existing `CNAME` file created by GitHub for `mountainguide.vondadowns.com`.
3. Commit the files to the `main` branch.
4. Wait 1–3 minutes for GitHub Pages to redeploy.
5. Open `https://mountainguide.vondadowns.com` in Safari and refresh.

## Privacy

This public version intentionally omits exact home address, lodging addresses, confirmation numbers, costs, and personal contact details.
