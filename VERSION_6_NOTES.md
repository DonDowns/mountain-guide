# Version 6 design rationale

Version 6 deliberately prioritizes three improvements:

1. **Faster field decisions:** Summit Focus combines start, first light, turn/exit, saved forecast, route links and the central safety principle on one screen.
2. **Low-light usability:** Night Vision changes the complete interface to a red/black palette suitable for pre-dawn camp use.
3. **A stronger personal identity:** the cinematic hero and memory illustrations prepare the interface for Don's Holy Cross, Mount Massive sunrise and Mount Princeton family photographs without requiring a later redesign.

No server, user account, tracking, private API key or public personal-detail database was added.
