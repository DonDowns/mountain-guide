DON DOWNS MOUNTAIN GUIDE — VERSION 6.1 UPLOAD

1. Open DonDowns / mountain-guide on GitHub.
2. Add file → Upload files.
3. Upload every extracted file from this folder.
4. Keep CNAME.
5. Commit directly to main.
6. Commit message: Deploy Mountain Guide v6.1 Refined Alpine Edition
7. Wait 1–3 minutes.
8. Hard refresh: Command + Shift + R.
9. Open the installed iPhone app and use Update now if shown.
10. Verify Summit Focus, Night Vision, live weather, and Airplane Mode relaunch.

The obsolete capital-I Index.html is not included, but an upload cannot delete an already-existing repository file.
