DON DOWNS MOUNTAIN GUIDE — VERSION 6 ALPINE EDITION

1. Download and unzip Don_Downs_Mountain_Guide_V6.zip.
2. Open GitHub: DonDowns / mountain-guide.
3. Click Add file → Upload files.
4. Drag every extracted Version 6 file into GitHub.
5. Do not delete CNAME.
6. Commit message: Deploy Mountain Guide v6 Alpine Edition
7. Commit directly to main.
8. Wait 1–3 minutes.
9. Open https://mountainguide.vondadowns.com and use Command + Shift + R on Mac.
10. On iPhone, close and reopen the installed app; accept Update now if shown.
11. Open Summit Focus, test Night Vision, refresh weather, and retest Airplane Mode.

The obsolete capital-I Index.html is not in this package. Uploading Version 6 will not delete it from GitHub; remove it separately when convenient.
