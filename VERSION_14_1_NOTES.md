# Version 14.1 — Audit Fix, Weather Cross-Checks, and Agreement

- Fixes Claude audit defect P-1: search input now uses a 150 ms debounce and updates only the search-results panel.
- Renames the visible Mountain Intelligence Engine heading to Expedition Insights.
- Retains NWS/NOAA as the only automated weather source.
- Adds links to 14ers.com, Mountain-Forecast, SummitCAST, OpenSnow, Windy, and inReach Weather instructions.
- Adds per-trip source-review timestamps.
- Adds manual objective agreement scoring for wind, temperature, storm/precipitation timing, and cloud cover.
- Agreement confidence is based only on entered source comparisons and review count.
- No subjective field interpretation, forecast accuracy claim, or safety conclusion is generated.
